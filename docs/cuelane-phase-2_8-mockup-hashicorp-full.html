How Windows Work

Windows represent teller counters, booths, or service stations in your branch. When an employee logs in, they pick a window from the available list — occupied windows show a lock icon and the current occupant's name. If an employee forgets to log out, the window auto-releases after 30 minutes idle, or you can force-release it manually below.
